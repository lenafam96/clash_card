Thẻ Bài Clash — So Sánh 2 Nick

Bấm vào thẻ để tăng số lượng (0 → x1 → x2 → x3 → quay lại 0). Dữ liệu được lưu tự động vào bộ nhớ trình duyệt (localStorage) trên máy này. Dùng nút "Xuất" ở mỗi cột để tải file JSON gửi cho người chơi khác, và "Nhập" để nạp file họ gửi lại — logic này nằm trong file app.js riêng. Bên dưới là gợi ý trao đổi thẻ dư giữa 2 nick.

Chưa có (0) Đã có (x1) Có nhiều (x2 / x3) 🔺 = thẻ nick kia đang thiếu, gợi ý đem đổi

🔁 Gợi ý trao đổi thẻ

Thẻ nào một nick có > 1 (dư) mà nick còn lại đang có 0 (chưa có) sẽ được gợi ý ở đây.

⇄ Có thể đổi 1:1 ngay

    A dư, B đang thiếu
